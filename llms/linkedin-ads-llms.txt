# LinkedIn Marketing API

> The LinkedIn Marketing API Program is a versioned REST surface at
> https://api.linkedin.com/rest for building and reporting on LinkedIn
> advertising: ad accounts, campaign groups, campaigns, creatives, audience
> targeting and sizing, budget/bid pricing, conversions, lead sync, matched
> audiences, media planning, community management and company intelligence.
> Authentication is OAuth 2.0 three-legged (authorization code). Every call must
> carry a dated version header (`Linkedin-Version: YYYYMM`, currently 202607) and
> `X-Restli-Protocol-Version: 2.0.0`. LinkedIn publishes no OpenAPI, no AsyncAPI,
> no GraphQL schema and no MCP server; the machine-readable artifacts here are
> API Evangelist derivations from the published documentation.

## Reading this

- Base URL: https://api.linkedin.com/rest
- Versions live a minimum of 12 months and then sunset; a call with a sunset version fails with HTTP 426.
- Access is granted, not purchased: Development and Standard access tiers, applied for in the Developer Portal.
- There is no idempotency key. Retrying a POST creates a second entity.
- There are no rate-limit response headers. You learn your quota from the Developer Portal Analytics tab, and you learn you exceeded it from a 429.
